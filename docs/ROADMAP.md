# SecondBrain AI Roadmap

## Phase 0 — Foundation ✅

- Project setup
- Git & GitHub
- Python environment
- FastAPI backend
- Documentation
- Project structure

---

## Phase 1 — Source Ingestion

Goal:
Allow users to upload knowledge from multiple sources.

Tasks:
- PDF upload
- PPT upload
- Image upload (OCR)
- YouTube transcript extraction
- Audio transcription
- Metadata extraction

Deliverable:
A unified ingestion pipeline for all supported sources.

---

## Phase 2 — Knowledge Extraction

Goal:
Convert raw content into structured knowledge.

Tasks:
- Text extraction
- Chunking
- Embedding generation
- Claim extraction
- Entity extraction
- Relationship detection

Deliverable:
Structured knowledge instead of raw documents.

---

## Phase 3 — Knowledge Fusion

Goal:
Merge knowledge from multiple sources.

Tasks:
- Merge duplicate claims
- Preserve evidence
- Detect contradictions
- Detect missing concepts
- Build unified understanding

Deliverable:
Knowledge Fusion Engine.

---

## Phase 4 — Knowledge Graph

Goal:
Visualize connected knowledge.

Tasks:
- Graph generation
- Concept linking
- Interactive graph
- Evidence navigation

Deliverable:
Interactive knowledge graph.

---

## Phase 5 — AI Chat

Goal:
Grounded conversational assistant.

Tasks:
- Context retrieval
- Citation support
- Conversation memory
- Follow-up reasoning

Deliverable:
Reliable AI assistant backed by uploaded knowledge.
